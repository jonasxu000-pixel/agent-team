## 本地开发协作入口

- 普通开发、小改动和一般 Bug 由 Codex 直接完成，不为每个任务启动多 Agent。用户明确要求“使用多 Agent”“让 Claude 参与”“进行独立 AI 审查”或调用 agent-team 时，读取用户级 `~/.agents/skills/agent-team/SKILL.md`，实际使用现有协调器。
- 复杂算法、关键并发状态、权限安全或多次修复失败时，可在有具体独立收益且当前开发已授权的范围内考虑 Selective；不因关键词或“多模型可能更好”自动升级流程。
- 启动前自动识别当前 Git 根目录并检查本项目测试和 AGENTS 约定；具体项目路径/测试保存在项目配置，不放进全局规则。项目更具体的工作约定、只读范围和已有授权继续有效。
- Claude 仅按需参与。明确多Agent默认授权用户级普通单任务$3；只有明确无人值守意图才授权$8，上海每日$15、月钱包$100；均可修改且为平台额度。钱包已在这些范围内授权，普通开发/GPT-only不授权Claude，更小金额收紧；超额或价格未知先确认，缺少专家成果如实标记。任务分工与阶段权限按Skill执行。
- 已由 agent-team 委派的角色、其 child 环境或管理工作区直接执行职责，绝不递归启动同一协调器。只读审查不擅自变成开发；不得自动合并、推送、部署或改变认证/计费渠道。
- 对现有 Agent Team 任务的监控、暂停、修改需求、接管、交还及继续意图，读取同一 Skill 的控制说明并操作原 Task ID；仅在协调器状态和所有权确认后报告操作完成。
